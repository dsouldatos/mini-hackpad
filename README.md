# Mini Keyboard 🎛️

A compact custom-designed mini keyboard featuring **4 mechanical-style switches** and a **rotary encoder**. The keyboard is designed to be small, simple, and customizable while keeping a clean modern look.

## ✨ Features

* 4 customizable switches
* 1 rotary encoder
* Custom-designed PCB
* Custom 3D-printed case
* Compact and portable design
* LED lighting
* Designed in CAD
* Easy to customize and modify

## 🛠️ Components

* Custom PCB
* Seeeduino XIAO microcontroller
* 4 switches
* 1 rotary encoder
* LEDs
* 3D-printed enclosure
* USB connection

## 📁 Project Files

* `PCB/` – PCB design files
* `CAD/` – 3D models and enclosure
* `Firmware/` – Keyboard firmware
* `Images/` – Project photos
* `README.md` – Project information

The PCB and enclosure have been designed, and the project is currently being assembled and tested.
