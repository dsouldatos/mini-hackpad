# Mini Keyboard 🎛️

A compact custom-designed mini keyboard featuring **4 mechanical-style switches** and a **rotary encoder**. The keyboard is designed to be small, simple, and customizable while keeping a clean modern look.

## ✨ Features

* 4 customizable switches
* 1 rotary encoder
* Custom-designed PCB
* Custom 3D-printed case
* Compact and portable design
* LED lighting
* Designed in CAD
* Easy to customize and modify
